# Encargos de Axia CYA para Axia RH

Lo escribe el Cerebro de Axia CYA. El Cerebro de Axia RH solo marca cada encargo como atendido, con fecha y dónde quedó registrado.

Antes de pedir una variable, buscarla en `base-comun/diccionario-variables.md`: muchas de las que usa la comisión ya existen (SINDICATO, DESIGNACION_OBRERA, NUM_REPRESENTANTES_POR_PARTE, REPRESENTANTES_SUPLENTES, MOD_PRUEBA, CLASIFICACION, PERFIL_CAPACITACION, TRAB_ESCOLARIDAD).
